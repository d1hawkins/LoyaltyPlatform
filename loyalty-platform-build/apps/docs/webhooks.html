Webhooks

Receive real-time HTTP notifications for loyalty platform events with HMAC-SHA256 signature verification and automatic retries.

Overview

The webhook system delivers events to your registered HTTP endpoints. Events flow through Azure Service Bus, are persisted to a durable delivery table, and then dispatched via HTTP POST with retry logic.

Platform Event --> Service Bus --> Webhook Worker --> webhook_deliveries (DB)
                                                            |
                                         Delivery Loop ---->|  POST your-endpoint.com
                                           2xx = delivered
                                           5xx = retry (exponential backoff)
                                           4xx = permanent failure

HTTP Request Format

Each webhook delivery sends a POST request with these headers:

HeaderValue
Content-Typeapplication/json
X-Loyalty-EventEvent type (e.g. points.earned)
X-Loyalty-Signaturesha256={hex} -- HMAC-SHA256 signature
X-Loyalty-Delivery-IdUnique delivery UUID (use for idempotency)
X-Loyalty-TimestampISO-8601 timestamp used in signature

Signature Verification

Verify that webhook requests originate from the Loyalty Platform by checking the HMAC-SHA256 signature.

Canonical String

{timestamp}.{raw_request_body}

Verification (Node.js)

import crypto from 'crypto';

function verifyWebhookSignature(
  secret: string,
  timestamp: string,
  body: string,
  signature: string
): boolean {
  const canonical = `${timestamp}.${body}`;
  const expected = 'sha256=' + crypto
    .createHmac('sha256', secret)
    .update(canonical)
    .digest('hex');
  return crypto.timingSafeEqual(
    Buffer.from(expected),
    Buffer.from(signature)
  );
}

// In your Express handler:
app.post('/webhooks/loyalty', (req, res) => {
  const isValid = verifyWebhookSignature(
    process.env.WEBHOOK_SECRET,
    req.headers['x-loyalty-timestamp'],
    JSON.stringify(req.body), // or raw body
    req.headers['x-loyalty-signature']
  );

  if (!isValid) {
    return res.status(401).send('Invalid signature');
  }

  // Use X-Loyalty-Delivery-Id for idempotency
  const deliveryId = req.headers['x-loyalty-delivery-id'];

  // Process the event
  const { eventType, payload } = req.body;
  switch (eventType) {
    case 'points.earned':
      handlePointsEarned(payload);
      break;
    case 'member.enrolled':
      handleMemberEnrolled(payload);
      break;
    // ...
  }

  res.status(200).send('OK');
});

Retry Schedule

Failed deliveries are retried with exponential backoff. 4xx responses are treated as permanent failures and are not retried.

AttemptWait Before Next
130 seconds
22 minutes
310 minutes
41 hour
56 hours

After 5 failed attempts, the delivery is marked dead and a webhook.delivery.failed event is emitted.

Timeout
Your endpoint must respond within 10 seconds. For long-running processing, acknowledge the webhook immediately and process asynchronously.

Managing Webhooks

Use the Admin API to register, test, and monitor webhooks.

Register a Webhook

curl -X POST https://loyalty-dev-apim-5rdrqh.azure-api.net/v1/admin/webhooks \
  -H "Content-Type: application/json" \
  -H "Ocp-Apim-Subscription-Key: YOUR_KEY" \
  -H "X-Tenant-ID: YOUR_TENANT_ID" \
  -H "X-User-Role: manager" \
  -H "X-Skip-Auth: true" \
  -d '{
    "targetUrl": "https://your-server.com/webhooks/loyalty",
    "secret": "your-shared-secret",
    "events": ["points.earned", "member.enrolled"]
  }'

Send a Test Event

curl -X POST https://loyalty-dev-apim-5rdrqh.azure-api.net/v1/admin/webhooks/{hookId}/test \
  -H "Ocp-Apim-Subscription-Key: YOUR_KEY" \
  -H "X-Tenant-ID: YOUR_TENANT_ID" \
  -H "X-User-Role: manager" \
  -H "X-Skip-Auth: true"

View Delivery History

curl "https://loyalty-dev-apim-5rdrqh.azure-api.net/v1/admin/webhooks/{hookId}/deliveries?status=dead&limit=50" \
  -H "Ocp-Apim-Subscription-Key: YOUR_KEY" \
  -H "X-Tenant-ID: YOUR_TENANT_ID" \
  -H "X-User-Role: manager" \
  -H "X-Skip-Auth: true"

Retry a Failed Delivery

curl -X POST https://loyalty-dev-apim-5rdrqh.azure-api.net/admin/webhooks/deliveries/{deliveryId}/retry \
  -H "Ocp-Apim-Subscription-Key: YOUR_KEY" \
  -H "X-Tenant-ID: YOUR_TENANT_ID" \
  -H "X-Skip-Auth: true"

Best Practices

  • Respond quickly -- return 200 within 10 seconds. Process asynchronously for heavy work.
  • Idempotency -- use X-Loyalty-Delivery-Id to deduplicate. The same event may be delivered more than once.
  • Verify signatures -- always validate the HMAC signature before processing.
  • Handle all event types -- gracefully ignore unknown eventType values for forward compatibility.
  • Return 2xx for success -- any 2xx status code is accepted. 4xx is a permanent failure. 5xx triggers retry.
