Daiso Rewards API

Build on the Daiso Rewards platform with points, tiers, offers, and rewards. API-first, production-ready. Supports per-dollar and per-visit earn modes, visit-based offers with qualification rules, self-checkout kiosk integration, full transaction enrichment, and comprehensive reporting across finance, marketing, and operations.

Base URL
All API requests go through the APIM gateway at https://loyalty-dev-apim-5rdrqh.azure-api.net

Core Capabilities

CapabilityDescription
Member ManagementEnrollment, lookup by phone/email, profile updates, GDPR delete & export
Points & TransactionsPer-dollar or per-visit earn modes, category/tier multipliers, immutable ledger, transaction enrichment (store, associate, source, order ref)
Offers & Redemptions6 offer types (percent, fixed, BOGO, threshold, visit-based, free item), qualification rules, code generation, eligibility engine
Tier SystemConfigurable tiers with multipliers and auto-evaluation on points changes
ReportingFinance (liability, breakage, redemption reserve), Marketing (funnel, at-risk, tier distribution), Operations (visit analytics, program health)
IntegrationsActiveCampaign and Klaviyo sync, profile properties, event tracking for automation flows
Self-CheckoutCustomer-facing kiosk app with phone keypad, item scanning, offer display, and points animation
Member PortalCustomer dashboard with points, tiers, collapsible transaction history, offers with visit progress, and profile management
WebhooksReal-time HTTP delivery of all platform events with HMAC signing
Multi-TenancyFull data isolation per tenant with per-tenant databases and encryption
Fraud DetectionVelocity checks, enrollment patterns, configurable rules with real-time blocking
Code-Bound CouponsVisit milestone coupon codes are bound to the earning member and single-use — prevents sharing and reuse fraud
Points ExpiryConfigurable expiry windows, notification reminders, admin dry-run tools

     +-- /engine/*   -->  Loyalty Engine    (port 3002)
     +-- /v1/offers  -->  Offer Service     (port 3004)
     +-- /v1/admin   -->  Admin API         (port 3005)
     +-- /v1/analytics -> Analytics Service (port 3006)

     +-- Service Bus (events) --> Webhook Worker (port 3009)
