E-Commerce Integrations

Ready-to-use integrations for Shopify and WooCommerce with automatic point awards, balance widgets, and checkout redemptions.

Shopify Integration

Architecture

Shopify Store
  |
  |-- orders/create webhook --> Your server (webhook handler)
  |                                |
  |                                +--> Loyalty Platform API (recordTransaction)
  |
  |-- Storefront theme (Liquid) --> Loads loyalty-sdk.umd.js
  |                                    |
  |                                    +--> Loyalty Platform API (getBalance, getOffers)
  |
  |-- Checkout Extension --> Applies offer redemption at checkout

Prerequisites

  • A Loyalty Platform tenant with an active API subscription key
  • Shopify store with admin access
  • Node.js 18+ (for webhook handler)

Step 1: Set Up Webhook Handler

The webhook handler receives Shopify orders/create webhooks and records them as loyalty transactions.

  1. Copy shopify-webhook-handler.ts to your server project
  2. Install dependencies: 
    npm install @loyalty/loyalty-js-sdk express crypto
  3. Configure environment variables: 
    LOYALTY_API_URL=https://loyalty-dev-apim-5rdrqh.azure-api.net
LOYALTY_API_KEY=your-subscription-key
LOYALTY_TENANT_ID=your-tenant-id
SHOPIFY_WEBHOOK_SECRET=your-shopify-webhook-secret
  4. Deploy to your server (Azure Functions, AWS Lambda, or Express)

Step 2: Register Webhook in Shopify

  1. Go to Settings > Notifications > Webhooks in Shopify Admin
  2. Create webhook:
    • Event: Order creation
    • Format: JSON
    • URL: https://your-server.com/webhooks/shopify/orders
  3. Copy the signing secret and set it as SHOPIFY_WEBHOOK_SECRET

Step 3: Display Points in Storefront

Add the Liquid snippet to your theme:

{% include 'loyalty-balance' %}

The snippet loads the SDK via CDN and renders a balance widget for the logged-in customer.

Step 4: Checkout Extension (Optional)

Use the checkout extension scaffold to apply loyalty offer redemptions during Shopify checkout using Shopify Functions.

WooCommerce Integration

Architecture

WooCommerce
  |
  |-- woocommerce_payment_complete hook
  |       |
  |       +--> PHP REST call to Loyalty Platform API (recordTransaction)
  |
  |-- [loyalty_balance] shortcode
  |       |
  |       +--> Loads loyalty-sdk.umd.js
  |       +--> Renders balance widget via JS SDK
  |
  |-- My Account tab
          |
          +--> PHP REST call to get balance + ledger

Prerequisites

  • A Loyalty Platform tenant with an active API subscription key
  • WordPress site with WooCommerce installed
  • PHP 7.4+

Installation

  1. Copy woocommerce-plugin.php and woocommerce-widget.php to wp-content/plugins/loyalty-platform/
  2. Activate the plugin in WordPress Admin > Plugins
  3. Navigate to Settings > Loyalty Platform and configure:
    • API URL: Your APIM gateway URL
    • API Key: Your APIM subscription key
    • Tenant ID: Your tenant identifier

Features

Automatic Points on Purchase

When an order is marked as paid (woocommerce_payment_complete), the plugin:

  1. Looks up the customer by email in the Loyalty Platform
  2. Records the transaction with the order total and line items
  3. Stores the points earned as order meta for reference

Balance Widget Shortcode

Display the points balance anywhere in your theme:

[loyalty_balance]
[loyalty_balance width="300px" show_offers="true"]
OptionDefaultDescription
width100%Widget container width
show_offersfalseAlso display eligible offers

My Account Tab

The plugin adds a "Loyalty Points" tab to the WooCommerce My Account page showing the customer's current balance and recent ledger entries.

Hooks and Filters

// PHP: Modify transaction data before sending
add_filter('loyalty_platform_transaction_data', function($data, $order) {
    $data['locationId'] = 'store-main';
    return $data;
}, 10, 2);

// PHP: Action fired after points are awarded
add_action('loyalty_platform_points_awarded', function($order_id, $points, $balance) {
    // e.g., send a custom email
}, 10, 3);

Troubleshooting

Shopify

IssueSolution
Webhook not firingVerify the webhook URL is publicly accessible and returns 200
Duplicate pointsThe handler uses the Shopify order ID as idempotency key
Member not foundEnsure customer email in Shopify matches the enrolled member email
Rate limitsThe platform allows 1,000 requests/minute per subscription key

WooCommerce

IssueSolution
No points awardedCheck that the customer email matches an enrolled loyalty member
Plugin settings not savingEnsure the user has manage_options capability
Widget not loadingVerify the CDN URL for the JS SDK bundle is correct
API errorsCheck the WordPress debug log (wp-content/debug.log)
