Quick Start Guide

Enroll a member, record a transaction, and check their points balance in under 5 minutes.

Prerequisites

  • An APIM subscription key (see Authentication)
  • A tenant ID (provided when your tenant is provisioned)
  • curl or any HTTP client
Dev Mode
For local development, all services support SKIP_AUTH=true mode. Send X-Skip-Auth: true through APIM, or set the header directly when calling services locally. See Authentication > Dev Mode.

Step 1: Enroll a Member

Create a new loyalty member with their phone number and name.

curl -X POST https://loyalty-dev-apim-5rdrqh.azure-api.net/member/v1/members \
  -H "Content-Type: application/json" \
  -H "Ocp-Apim-Subscription-Key: YOUR_SUBSCRIPTION_KEY" \
  -H "X-Tenant-ID: YOUR_TENANT_ID" \
  -H "X-Skip-Auth: true" \
  -d '{
    "phone": "+15555551234",
    "firstName": "Jane",
    "lastName": "Doe",
    "email": "jane@example.com",
    "enrolledChannel": "ecommerce"
  }'

Response (201 Created):

{
  "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "tenantId": "YOUR_TENANT_ID",
  "status": "active",
  "tierId": "bronze-tier-id",
  "tierName": "Bronze",
  "pointsBalance": 0,
  "firstName": "Jane",
  "lastName": "Doe",
  "email": "jane@example.com",
  "phone": "+15555551234",
  "enrolledChannel": "ecommerce",
  "enrolledAt": "2026-04-10T12:00:00Z",
  "createdAt": "2026-04-10T12:00:00Z",
  "updatedAt": "2026-04-10T12:00:00Z"
}
Duplicate Detection
If a member with the same phone or email already exists, you will receive a 409 DUPLICATE_MEMBER error with the existingMemberId in the response body.

Step 2: Record a Transaction

Award points for a purchase. Amounts are in minor currency units (cents for USD).

curl -X POST https://loyalty-dev-apim-5rdrqh.azure-api.net/engine/v1/transactions \
  -H "Content-Type: application/json" \
  -H "Ocp-Apim-Subscription-Key: YOUR_SUBSCRIPTION_KEY" \
  -H "X-Tenant-ID: YOUR_TENANT_ID" \
  -H "X-Skip-Auth: true" \
  -H "Idempotency-Key: order-12345" \
  -d '{
    "memberId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
    "channel": "ecommerce",
    "amount": 4999,
    "currency": "USD",
    "skuList": [
      { "sku": "LATTE-LG", "categoryId": "beverages", "amount": 4999 }
    ],
    "storeId": "DAISO-042",
    "storeName": "Daiso Carrollton",
    "registerId": "REG-01",
    "associateId": "EMP-1001",
    "associateName": "Jane Smith",
    "sourceChannel": "in-store",
    "sourceSystem": "square",
    "orderRef": "ORD-2026-04-16-5523",
    "metadata": { "campaign": "spring-sale" }
  }'

Response (201 Created) — per-dollar mode:

{
  "transactionId": "txn-uuid-here",
  "pointsEarned": 49,
  "newBalance": 49,
  "tierId": "bronze-tier-id",
  "earnMode": "per-dollar",
  "appliedMultipliers": [
    { "source": "category:beverages", "multiplier": 2, "points": 49 }
  ]
}

Response (201 Created) — per-visit mode (if the program is configured for per-visit earning):

{
  "transactionId": "txn-uuid-here",
  "pointsEarned": 10,
  "newBalance": 10,
  "tierId": "bronze-tier-id",
  "earnMode": "per-visit",
  "qualifiedVisit": true,
  "visitCountToday": 1,
  "appliedMultipliers": [
    { "source": "tier:bronze", "multiplier": 1, "points": 10 }
  ]
}

In per-visit mode, the qualifiedVisit field indicates whether this transaction met the minimum spend threshold to earn points. The visitCountToday field shows the member's qualifying visit count for the current day.

Idempotency
Always include an Idempotency-Key header on write operations. Replaying the same key with the same body returns the original response. Using the same key with a different body returns 409 Conflict. Keys expire after 24 hours.

Step 3: Check Balance

curl https://loyalty-dev-apim-5rdrqh.azure-api.net/engine/v1/members/a1b2c3d4-e5f6-7890-abcd-ef1234567890/balance \
  -H "Ocp-Apim-Subscription-Key: YOUR_SUBSCRIPTION_KEY" \
  -H "X-Tenant-ID: YOUR_TENANT_ID" \
  -H "X-Skip-Auth: true"
{
  "balance": 49,
  "lastUpdated": "2026-04-10T12:01:00Z"
}

Step 4: Look Up a Member

Find a member by phone number (the hot-path lookup for POS integrations):

curl "https://loyalty-dev-apim-5rdrqh.azure-api.net/member/v1/members?phone=%2B15555551234" \
  -H "Ocp-Apim-Subscription-Key: YOUR_SUBSCRIPTION_KEY" \
  -H "X-Tenant-ID: YOUR_TENANT_ID" \
  -H "X-Skip-Auth: true"
{
  "id": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "firstName": "Jane",
  "lastName": "Doe",
  "tierId": "bronze-tier-id",
  "tierName": "Bronze",
  "pointsBalance": 49,
  "eligibleOffers": []
}

Using the JavaScript SDK

The same flow using the TypeScript SDK:

import { LoyaltyClient } from '@loyalty/loyalty-js-sdk';

const client = new LoyaltyClient({
  apiUrl: 'https://loyalty-dev-apim-5rdrqh.azure-api.net',
  apiKey: 'YOUR_SUBSCRIPTION_KEY',
  tenantId: 'YOUR_TENANT_ID',
});

// 1. Enroll
const member = await client.enrollMember({
  phone: '+15555551234',
  firstName: 'Jane',
  lastName: 'Doe',
  email: 'jane@example.com',
  enrolledChannel: 'ecommerce',
});

// 2. Record transaction
const txn = await client.recordTransaction({
  memberId: member.id,
  channel: 'ecommerce',
  amount: 4999,
  currency: 'USD',
  skuList: [{ sku: 'LATTE-LG', categoryId: 'beverages', amount: 4999 }],
});

console.log(`Points earned: ${txn.pointsEarned}, Balance: ${txn.newBalance}`);

// 3. Check balance
const { balance } = await client.getBalance(member.id);
console.log(`Current balance: ${balance}`);
