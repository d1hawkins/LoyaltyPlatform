1. Getting Started

Logging In

Open the Admin Portal at https://loyaltyadminportal.z20.web.core.windows.net. Sign in with your administrator credentials. If you do not have credentials, contact your system administrator to provision an account.

Dashboard Overview

After logging in, you'll see the Dashboard — your real-time command center for the loyalty program. The dashboard displays:

  • Active Members: Total enrolled members with active status
  • Points Issued Today: Total points awarded across all transactions today
  • Transactions Today: Number of loyalty transactions processed
  • Program Health: Key metrics including redemption rate, engagement rate, and tier distribution

Understanding Your Role

As a Loyalty Admin, you have full access to all program management features:

FeatureAccess Level
View Dashboard & ReportsFull access
Manage MembersSearch, view, adjust points, change status
Manage TiersCreate, edit, delete tiers
Manage OffersCreate, edit, activate, deactivate offers
Program ConfigurationEarn rate, expiry, multipliers
API Keys & WebhooksGenerate, rotate, configure
Audit LogView all admin actions

2. Managing Members

Searching for Members

Navigate to Members in the left sidebar. Use the search bar to find members by:

  • Phone number: Enter the full number (e.g., 9192474109)
  • Email address: Enter the complete email
  • Name: Enter first name, last name, or both
  • Member ID: Enter the UUID if known

Viewing a Member Profile

Click on any member in the search results to open their detail view. The profile shows:

  • Personal Information: Name, phone, email, enrollment date, enrollment channel
  • Loyalty Status: Current tier, points balance, lifetime points earned
  • Transaction History: All purchases with date, store, items, and points earned
  • Points Ledger: Every points credit and debit with reasons and timestamps
  • Active Offers: Offers currently assigned to this member

Adjusting Points

To manually add or deduct points from a member's balance:

  1. Open the member's profile
  2. Click Adjust Points
  3. Enter the number of points (positive to add, negative to deduct)
  4. Select a reason (goodwill, correction, promotion, other)
  5. Add an optional note explaining the adjustment
  6. Click Submit
Important
All point adjustments are logged in the audit trail with your admin identity, the reason, and the before/after balance. This cannot be undone — to reverse an adjustment, create another adjustment in the opposite direction.

Overriding a Member's Tier

In some cases, you may need to manually promote or demote a member:

  1. Open the member's profile
  2. Click Override Tier
  3. Select the target tier from the dropdown
  4. Add a note explaining the override reason
  5. Click Apply

The member will retain the new tier until the next automatic tier evaluation occurs (based on your program configuration).

Changing Member Status

Members can have the following statuses:

StatusDescription
activeNormal, fully functional member account
suspendedTemporarily disabled — cannot earn or redeem, but data is preserved
closedPermanently closed — points forfeited, account deactivated

GDPR Data Deletion

When a member requests data deletion under GDPR or CCPA:

  1. Open the member's profile
  2. Click Actions → Delete Member Data
  3. Confirm the deletion — this action is irreversible
  4. The system will anonymize PII (name, email, phone) while retaining anonymized transaction records for financial reporting

3. Managing Tiers

Understanding Tiers

Tiers are configurable levels that members progress through based on their loyalty activity. The default configuration includes:

TierThresholdEarn MultiplierExample Benefits
Bronze0 points1xBase earn rate, access to member offers
Silver500 points1.25xEarly access to sales, birthday bonus
Gold1,500 points1.5xFree shipping, exclusive offers
Platinum5,000 points2xVIP events, premium support, all Gold benefits

Creating or Editing a Tier

  1. Navigate to Tiers in the sidebar
  2. Click Add Tier or click an existing tier to edit
  3. Configure:
    • Name: Display name shown to members
    • Point Threshold: Minimum points to qualify
    • Earn Multiplier: Points multiplier for this tier (e.g., 1.5 = 50% more points)
    • Benefits: List of benefits shown in the member portal
  4. Click Save

Auto-Promotion and Demotion

The platform automatically evaluates tier eligibility when a member's points balance changes:

  • Promotion: When a member earns enough points to qualify for a higher tier, they are promoted immediately. A tier.upgraded event is emitted for webhook consumers.
  • Demotion: Tier demotion can be configured to occur at a set evaluation period (e.g., annually). Members are notified before demotion via the configured notification channel.

4. Managing Offers

Offer Types

TypeDescriptionExample
Percentage DiscountPercentage off the transaction total15% off your next purchase
Fixed AmountDollar amount off the transaction$5 off when you spend $25+
BOGOBuy one, get one free or discountedBuy 2 storage bins, get 1 free
Threshold RewardReward after reaching a spending thresholdSpend $200 this month, get 500 bonus points
Visit-BasedReward after a number of qualifying visits5 visits of $5+, get $5 off

Creating an Offer

  1. Navigate to Offers → Create Offer
  2. Select the offer type
  3. Configure the reward:
    • Discount amount or percentage
    • Minimum purchase amount (if applicable)
    • Maximum discount cap (for percentage offers)
  4. Set qualification rules:
    • Visit count: Number of qualifying visits required
    • Minimum spend per visit: Minimum transaction amount to count as a qualifying visit
    • Minimum items per visit: Minimum number of items per transaction
    • Qualifying stores: Specific stores or all stores
  5. Set eligibility:
    • Tier requirement: Restrict to specific tiers
    • Channel: In-store, online, or both
    • Date range: Start and end dates
  6. Click Publish to activate immediately, or Save as Draft

Code-Bound Coupons (Visit Milestones)

Visit milestone coupons are code-bound — each code is tied to the member who earned it:

  • When a member reaches a visit milestone, a unique coupon code is generated and assigned exclusively to them
  • Codes are single-use and marked as redeemed after checkout
  • If a code is shared publicly (e.g., on social media), it cannot be used by another member
  • The system returns specific error codes: CODE_MEMBER_MISMATCH (wrong member), CODE_ALREADY_USED (reused), CODE_EXPIRED (expired)

Viewing Redemption Stats

Each offer displays performance metrics:

  • Total Issued: Number of members who received the offer
  • Total Redeemed: Number of successful redemptions
  • Redemption Rate: Percentage of issued offers that were redeemed
  • Total Discount Value: Sum of all discounts given
  • Average Basket Size: Average transaction value when the offer was redeemed

5. Program Configuration

Earn Rate

Configure how many points members earn per dollar spent:

  • Base Earn Rate: Default points per dollar (e.g., 1 point per $1.00)
  • Currency: Base currency for calculations (USD)
  • Rounding: How fractional points are handled (floor, ceiling, or nearest)

Points Expiry

Configure when earned points expire:

  • Expiry Window: Number of months after earning before points expire (e.g., 12 months)
  • Notification Schedule: When to send expiry warnings (e.g., 30 days and 7 days before expiry)
  • Grace Period: Optional window after expiry during which admin can restore points

Void Window

Configure how long after a transaction it can be voided:

  • Void Window: Number of hours after transaction creation (default: 24 hours)
  • Voiding a transaction automatically reverses the points earned
  • Voided transactions are marked in the ledger with a voided status

Promotional Multipliers

Run time-limited promotions that increase the earn rate:

  1. Navigate to Program Config → Promotional Multipliers
  2. Click Add Multiplier
  3. Configure:
    • Name: "Double Points Weekend" or "Holiday Bonus"
    • Multiplier: 2x, 3x, or any decimal value
    • Start Date/Time: When the promotion begins
    • End Date/Time: When the promotion ends
    • Applicable Stores: All stores or specific locations
  4. Click Save — the multiplier activates automatically at the start time

Category Multipliers

Award bonus points for specific product categories:

  • Navigate to Program Config → Category Multipliers
  • Set a multiplier for each product category (e.g., Beauty = 3x, Kitchen = 2x)
  • Category multipliers stack with tier multipliers and promotional multipliers
Multiplier Stacking
When multiple multipliers apply, they are multiplied together. For example: a Gold member (1.5x) buying beauty products (3x) during a double points weekend (2x) earns 1.5 x 3 x 2 = 9x the base rate. The transaction response shows all applied multipliers in the appliedMultipliers array.

6. Webhooks

Registering a Webhook Endpoint

  1. Navigate to Webhooks in the sidebar
  2. Click Add Endpoint
  3. Enter the target URL (must be HTTPS)
  4. Select the events you want to receive:
    • member.enrolled — New member registration
    • transaction.completed — Points earned from a purchase
    • transaction.voided — Transaction reversed
    • points.redeemed — Points used for a reward
    • tier.upgraded — Member promoted to a higher tier
    • tier.downgraded — Member demoted to a lower tier
    • offer.redeemed — Offer applied to a transaction
    • points.expiring — Points approaching expiry
  5. Click Save

Testing Delivery

After registering an endpoint, click Send Test to deliver a sample event. Check that your endpoint returns a 2xx response.

Delivery History

Each endpoint shows a delivery log with:

  • Timestamp of each delivery attempt
  • HTTP status code returned
  • Response time
  • Request and response bodies (for debugging)

Retry Policy

Failed deliveries are retried with exponential backoff:

  • 1st retry: 1 minute after failure
  • 2nd retry: 5 minutes
  • 3rd retry: 30 minutes
  • 4th retry: 2 hours
  • 5th retry: 12 hours

After 5 failed attempts, the delivery is marked as failed and the endpoint is flagged for review. See the Webhooks technical documentation for HMAC signature details.

7. API Keys

Generating a Key

  1. Navigate to API Keys
  2. Click Generate New Key
  3. Enter a descriptive name (e.g., "POS Integration - Production")
  4. Select the scope:
    • Full Access: All API endpoints
    • Transaction Only: Limited to member lookup, transactions, and balance
    • Read Only: GET endpoints only
  5. Click Create
  6. Copy the key immediately — it is only shown once
Security
API keys provide full programmatic access to your loyalty program data. Store them securely (e.g., Azure Key Vault, environment variables). Never commit keys to source control or share them in emails.

Rotating a Key

To rotate an API key without downtime:

  1. Generate a new key with the same scope
  2. Update your POS/integration to use the new key
  3. Verify the integration works with the new key
  4. Revoke the old key

Revoking a Key

Click the Revoke button next to any key. Revoked keys stop working immediately. This action cannot be undone.

8. Audit Log

Every administrative action is recorded in the audit log. Navigate to Audit Log to view all logged events.

What Is Logged

  • Point adjustments (who, amount, reason, before/after balance)
  • Tier overrides (who, from tier, to tier)
  • Member status changes (who, old status, new status)
  • Offer creation, updates, and deactivation
  • Program configuration changes (earn rate, multipliers, expiry)
  • API key generation and revocation
  • Webhook endpoint changes
  • GDPR data deletion requests

Filtering the Log

Filter audit entries by:

  • Admin User: Which administrator performed the action
  • Entity Type: Member, Offer, Tier, Config, API Key, etc.
  • Date Range: Start and end dates
  • Action Type: Create, Update, Delete

Exporting Audit Data

Click Export to download the filtered audit log as a CSV file. This is useful for compliance reviews and internal audits.

9. Earn Mode Configuration

Per-Dollar vs Per-Visit

The platform supports two earn modes. You can switch between them at any time in Program Config.

ModeHow It WorksBest For
Per-Dollar Members earn a configurable number of points for every dollar spent (e.g., 1 point per $1). Points scale with transaction amount. Higher-ticket retail where spend varies significantly between visits
Per-Visit Members earn a flat number of points for every qualifying visit (e.g., 10 points per visit). The transaction must meet a minimum spend threshold to qualify. High-frequency, low-ticket retailers like Daiso where most transactions are similar in value

Switching Earn Modes

  1. Navigate to Program Config
  2. Find the Earn Mode toggle at the top of the Earn Rate section
  3. Select Per-Dollar or Per-Visit
  4. If Per-Visit is selected, configure:
    • Points Per Visit: The flat number of points awarded per qualifying visit (e.g., 10)
    • Minimum Spend Threshold: The minimum transaction amount in dollars to count as a qualifying visit (e.g., $5.00)
    • Max Visits Per Day: Maximum number of qualifying visits per member per day (prevents gaming; e.g., 3)
  5. Click Save
Impact on Existing Points
Switching earn modes does not affect points already in members' accounts. Existing points balances, tiers, and offers remain unchanged. Only future transactions will use the new earn mode. Tier multipliers still apply to per-visit points (e.g., a Gold member with 1.5x multiplier earns 15 points per visit instead of 10).

10. Visit-Based Offers

How Visit-Based Offers Work

Visit-based offers act as digital punch cards. Members must complete a set number of qualifying visits to unlock the reward. Each qualifying transaction increments the member's visit counter for that offer.

Creating a Visit-Based Offer

  1. Navigate to Offers → Create Offer
  2. Select type: Visit-Based
  3. Set the reward: fixed amount off, percentage off, bonus points, or free item
  4. Set the visits required (e.g., 5)
  5. Configure qualification rules:
    • Minimum Spend: Minimum transaction amount to count as a qualifying visit (e.g., $5.00)
    • Minimum Items: Minimum number of line items per transaction (optional)
    • Qualifying Channels: In-store, online, self-checkout, or all
    • Qualifying Stores: All stores, or restrict to specific locations
    • Counting Mode: Per-Transaction (every qualifying transaction counts) or Per-Day (only the first qualifying transaction per day counts)
  6. Set eligibility: tier requirements, date range
  7. Click Publish or Save as Draft

Visit Progress Tracking

Members see their visit progress in three places:

  • Member Portal: Offers tab shows "3 of 5 visits — 2 more to unlock!"
  • POS Terminal: Member panel shows progress bars for active visit-based offers
  • Self-Checkout Kiosk: Visit progress is displayed after member identification

11. Free Item Offers

Free Item offers allow you to give a specific product or any product up to a maximum value as a reward.

  1. Navigate to Offers → Create Offer
  2. Select type: Free Item
  3. Configure the reward:
    • SKU (optional): If specified, only this product is free. If left blank, any single item up to the max value is free.
    • Max Value (optional): Maximum dollar value of the free item. If the item costs more, the member pays the difference.
  4. Set qualification rules (visits required, minimum spend, etc.) just like any other offer
  5. Click Publish
Example
Create a "Free storage bin after 5 visits" offer: type = Free Item, SKU = STORAGE-BIN-M, visits required = 5, min spend per visit = $5.00. Or leave SKU blank and set max value = $5.00 for "any free item up to $5."

13. Reports

Navigate to Reports in the sidebar. Reports are organized into three tabs:

Finance Tab

  • Points Liability: Outstanding points, gross liability, breakage estimate, and net liability (ASC 606 / IFRS 15 compliant)
  • Points Flow: Points issued, redeemed, expired, and voided over a selected period
  • Redemption Reserve: Monthly cash flow impact from redemptions with rolling averages and projections
  • Revenue Attribution: Member vs non-member revenue, average basket comparison, and spend lift percentage

Marketing Tab

  • Engagement Funnel: Conversion rates from enrollment through first purchase, repeat, tier upgrade, and redemption
  • At-Risk Members: Members with positive balance who haven't transacted in 60+ days, filterable by tier
  • Tier Distribution: Bar chart of member counts per tier
  • Offer Performance: Per-offer metrics including redemption rate, revenue attributed, and ROI

Operations Tab

  • Qualified Visits: Number of transactions that met the qualifying visit threshold
  • Visit Conversion Rate: Percentage of total transactions that qualify as visits (helps you tune the minimum spend threshold)
  • Daily Visit Trends: Chart of qualified visits over time
  • Program Health: Composite score based on enrollment rate, engagement, redemption rate, and visit frequency

Exporting Reports

Every report card includes an Export button to download data as CSV. See the Finance Guide for detailed reporting instructions and the Marketing Admin Guide for campaign analytics.

14. Integrations

Navigate to Integrations in the sidebar to connect external marketing platforms.

ActiveCampaign

  1. Click Connect next to ActiveCampaign
  2. Enter your API URL (e.g., https://yourcompany.api-us1.com) and API key
  3. Click Test Connection to verify
  4. Select which fields to sync (member ID, email, phone, tier, points balance, etc.)
  5. Click Enable Sync

Klaviyo

  1. Click Connect next to Klaviyo
  2. Enter your Klaviyo Private API Key (found in Account → Settings → API Keys)
  3. Click Test Connection
  4. Map loyalty fields to Klaviyo profile properties
  5. Click Enable Sync

Once connected, member profiles sync automatically. Loyalty events (enrollment, tier change, points earned, points expiring) are sent as trackable events for use in automation flows. See the Marketing Admin Guide for automation trigger setup.

15. Common Tasks

"A customer says they didn't get points for their purchase"

  1. Navigate to Members and search for the customer
  2. Open their profile and check Transaction History
  3. If the transaction is listed but points are missing, check the Points Ledger for errors
  4. If the transaction is not listed, check with the store to confirm the POS was connected
  5. If confirmed as a missed transaction, use Adjust Points with reason "correction" to award the points manually

"We want to run a double points weekend"

  1. Navigate to Program Config → Promotional Multipliers
  2. Click Add Multiplier
  3. Set Name = "Double Points Weekend", Multiplier = 2
  4. Set start to Friday 12:00 AM and end to Sunday 11:59 PM
  5. Select "All Stores" for applicable stores
  6. Click Save — it activates automatically at the scheduled time

See the Marketing Admin Guide for more promotion strategies.

"A member wants to merge two accounts"

The platform does not support automatic account merging. Handle manually:

  1. Identify the primary account (the one the member wants to keep)
  2. Open the secondary account and note the points balance
  3. Use Adjust Points on the primary account with reason "account merge" to add the secondary account's balance
  4. Change the secondary account's status to closed with a note referencing the primary account ID

"We need to void a transaction from earlier today"

  1. Navigate to Transactions
  2. Find the transaction by member, store, or order reference
  3. Click the transaction to open its detail view
  4. Click Void Transaction (available within the configured void window)
  5. Confirm — the points earned from this transaction will be automatically reversed

If the void window has expired, use Adjust Points on the member's profile to manually deduct the points.

"Finance needs the monthly liability report"

  1. Navigate to Reports → Finance
  2. The Points Liability card shows outstanding points, breakage estimate, and net liability
  3. Click Export to download as CSV for your finance team
  4. See the Finance Guide for detailed reporting instructions
